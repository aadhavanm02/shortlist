What's new

Every update to the web app and the Android app. Install the web app on your phone from the install page.

Version 2.0LatestWeb18 Nov 2026
  • Shortlist is now one web app for phone and desktop. Install it from Chrome or Safari, see the install page. The separate Android app is retired.
  • New home page.
  • Fixed: tapping your profile on the profile screen did nothing on phones.
  • An Install button in Settings and on the profile screen.
Version 1.0.8Android18 Nov 2026
  • Fixed a blank screen when opening the Android app in versions 1.0.6 and 1.0.7.
Version 1.0.7AndroidWeb18 Nov 2026
  • The web app in your phone's browser now looks and works like the Android app.
  • Android-style profile picker, setup screen, Settings and Resumes.
  • Install the web app from Chrome: open the menu and tap Add to Home screen or Install app. It opens full screen with the Shortlist icon.
Version 1.0.6AndroidWeb18 Nov 2026
  • New home page, with the web app now at /shortlist/app. Old links still open the app.
  • This changelog page.
  • Settings and the profile screen now show which version you are using.
Version 1.0.5Android18 Nov 2026
  • Each download is named with its version, like Shortlist-1.0.5.apk, so your phone never opens an older file by mistake.
  • A simple download page that always links the newest version.
Version 1.0.4Android18 Nov 2026
  • New Android design: bottom navigation for Jobs, Resumes and Settings.
  • Job screen with a back arrow, Job and Resume tabs, and a Tailor button that stays at the bottom.
  • Floating Refine button and a full-screen chat for refining your resume.
  • Filters open as a sheet from the bottom.
  • The phone's back button closes sheets and chat first, then goes back a screen.
Version 1.0.2Android18 Nov 2026
  • Signed with a permanent key, so new versions install over the old one and keep your data. If you installed 1.0.1, uninstall it once before installing a newer version.
Version 1.0.1Android18 Nov 2026
  • First Android app.
  • Resume PDFs save to Documents/Shortlist and open the share sheet.
  • A reminder at 7 AM when the day's jobs are ready.
  • Shortlist app icon and splash screen.
Web app updatesWeb18 Nov 2026
  • Nobody needs to enter API keys any more. They are kept safely on the server.
  • If Gemini is busy, the app retries, and refinements switch to the backup AI.
  • Fixed job search after the job source changed its address.
  • A preview image and title when you share the link.
